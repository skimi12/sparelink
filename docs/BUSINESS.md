# SpareLink — 事業仮説と検証計画

更新日：2026年11月25日（日本時間）

## 1. 現時点の判断

SpareLinkは、廃番・長納期の産業用部品について、部品を必要とする企業と余剰在庫を持つ企業をつなぐサービスの初期実装です。最初は国内企業の調達相談、在庫情報の登録、型番と条件の照合を対象にします。

**競合が解決できていない市場の空白、継続的な顧客獲得、料金への支払意思は、まだ確認できていません。** 実装の完成を事業性の検証完了として扱いません。下記の金額・件数・成約率は、実績ではなく検証用の仮説です。

初期公開版は一般利用者向けのデモです。一般利用者による実データの書き込みを停止し、管理者はD1を使ってテストできます。第三者への連絡送信、売買の締結、決済、実請求は行いません。実受付と有料運用への移行条件は [OPERATIONS.md](./OPERATIONS.md) に記載します。

## 3. 最初に検証する対象

### 対象の仮説

- 需要側：国内の小規模な設備保守会社・工場保全部門。
- 供給側：出所・保管状況を説明できる余剰部品を持つ国内企業・商社。
- 依頼：同一型番・少量の産業用制御部品を、必要日と許容状態を指定して探す案件。
- 初期の製品範囲候補：PLCのI/O・通信モジュール等。最初の案件を見てメーカーや製品系列を絞ります。
- 提供価値の仮説：型番末尾、仕様、状態、数量、必要日、在庫の確認日を整理し、購買担当者の照会・比較の手間を減らすこと。

この対象が競合未対応であるとは確認できていません。上記の部品を扱うと直ちに調達需要を獲得できる、という主張でもありません。安全用途の適合性判断、代替品の設計判断、修理作業、輸出入は、初期の提供範囲に含めません。

### 検証したい差別化

「既存業者が扱っていない」という説明から始めず、既存の調達手段を使った後に何が残るかを案件単位で記録します。

1. 在庫が見つからないのか、最小数量・納期・状態・価格が合わないのか。
2. 既存在庫の確認に時間がかかるのか、仕様の違いが判断できないのか。
3. 顧客が追加の調達支援に支払う条件は何か。
4. 手数料を含めても、顧客の既存調達手段より有利になるか。

「AIでは実物を作れない」という特徴だけでは収益性の根拠になりません。供給企業の協力、在庫情報の鮮度、条件を揃える運用、当事者の信頼を獲得する必要があります。

## 4. 採算モデル

### 前提はすべて仮説

| 変数 | 仮定値 | 定義 |
| --- | ---: | --- |
| 平均取引額 `V` | 50,000円 | 成約1件の部品代金の計算基準額 |
| 成約手数料率 `r` | 15% | 成約時に支払われると仮定する率 |
| 問い合わせからの成約率 `p` | 30% | 問い合わせを分母とする成約確率 |
| 問い合わせ1件の現金費用 `c` | 500円 | 集客・照会等の変動現金費用の仮定 |
| 問い合わせ1件の対応時間 `t` | 0.5時間 | 成約しない問い合わせも含む平均対応時間 |
| 自己労働の評価単価 `w` | 1,500円／時 | 創業者自身の時間の機会費用 |
| 月間固定費 `F` | 5,000円 | ホスティング等をまとめた仮定 |

この表はサービスの確定料金表ではありません。税抜・税込の表示方法、請求相手、料金発生条件、返金条件は有料化前に確定します。この簡易モデルでは税を別計算していません。

### 問い合わせ1件あたりの計算

```text
成約1件の売上            = V × r
                         = 50,000 × 0.15 = 7,500円

問い合わせ1件の期待売上  = p × V × r
                         = 0.30 × 7,500 = 2,250円

問い合わせ1件の労働費用  = t × w
                         = 0.5 × 1,500 = 750円

問い合わせ1件の期待貢献  = p × V × r − c − t × w
                         = 2,250 − 500 − 750 = 1,000円

月間期待利益             = N × 1,000 − 5,000円
```

ここでいう期待利益は、創業者の労働を時給1,500円で費用評価した数値です。創業者への現金給与を実際に支払ったという意味ではなく、会計・税務上の所得と同一でもありません。

### 月間10万円の目標に必要な規模

```text
必要問い合わせ数 = ceil((100,000 + 5,000) / 1,000) = 105件
期待成約数         = 105 × 0.30 = 31.5件
問い合わせ対応時間 = 105 × 0.5 = 52.5時間
```

| 月間の項目 | 105件の問い合わせの場合 |
| --- | ---: |
| 期待手数料売上 | 236,250円 |
| 変動現金費用 | 52,500円 |
| 自己労働の評価額 | 78,750円 |
| 固定費 | 5,000円 |
| 自己労働控除前の現金余剰 | 178,750円 |
| 自己労働を評価した期待利益 | 100,000円 |

31.5件は期待値であり、実際の月間成約数は整数です。毎月105件あれば必ず10万円を得られる、という意味ではありません。特に、問い合わせから入金までの時間差はこの計算に含みません。

以前の人件費を含めない試算では、問い合わせ1件の貢献は1,750円でした。今回の基準では自己労働750円を控除するため、同じ月10万円の目標に必要な問い合わせは60件から105件へ増えます。

### 成約率の感度

ほかの条件を固定し、労働費用も含めて計算した場合です。

| 成約率 | 問い合わせ1件の期待貢献 | 月10万円に必要な問い合わせ | 問い合わせ対応時間 |
| --- | ---: | ---: | ---: |
| 20% | 250円 | 420件 | 210時間 |
| 30% | 1,000円 | 105件 | 52.5時間 |
| 40% | 1,750円 | 60件 | 30時間 |

固定費を除く期待貢献が正になる条件は `p > (500 + 750) / 7,500`、つまり成約率約16.7%超です。それだけでは月間固定費を回収できるとは限りません。

### このモデルに含まないもの

- 税、決済手数料、未回収・返金・不良品・紛争の損失。
- サプライヤーの開拓、契約整備、サイト開発、経理、継続的な在庫確認に要する時間。
- 問い合わせの複雑さによる工数のばらつき、成約後に追加で発生する対応。
- 創業者が負担する送料・検査費・保証費。初期案では当事者間で定める方針ですが、実際に誰が払うかは未確定です。

30分は「問い合わせ当たりの平均総対応時間」として検証すべき数値です。照会・比較・紹介・成約後対応を別枠にすると採算を過大評価します。別に発生した工数は必ず記録し、式に追加します。

## 5. 最初の10件・供給5社で行う検証

これは小さな運用実験の計画であり、統計的に市場性を確定する標本数ではありません。実受付条件を満たした後、実在する調達依頼10件と、協力する供給企業5社を目安に進めます。デモ・重複・いたずら・仕様不明のまま中断した入力を、有効な調達依頼と混ぜません。

| 検証項目 | 記録する内容 |
| --- | --- |
| 需要の具体性 | 完全な型番、数量、必要日、状態条件、予算、既存調達の結果 |
| 供給の実在性 | 在庫確認日、数量、出所、状態の証拠、対応可能な条件 |
| 見積可能性 | 条件を満たす見積を提示できた件数／有効依頼数 |
| 成約 | 完了した売買件数。候補提示や紹介だけで成約扱いにしない |
| 料金への反応 | 15%等の具体的条件への意向。意向と実際の支払いを分ける |
| 工数 | 各案件の照会・比較・連絡・事後対応時間と、共通の営業時間 |
| 損失と障害 | 不適合、在庫切れ、辞退、トラブルの原因と対応費用 |

登録企業数だけでなく、条件が揃った案件を実際に処理できるかを評価します。需要側・供給側の聞き取りや営業連絡は、送信が明示的に依頼された場合に行います。この初期実装では連絡を送信していません。

有効依頼だけを分母にした成約率と、採算計算に使う全問い合わせベースの成約率は別に集計します。仕様不足等で除外した問い合わせにも対応時間・費用が発生した場合、その費用を除いて成約率だけを高く見せないでください。

### 継続判断の基準案

以下は事前に置く仮の基準です。10件での偶然を考慮し、単独の指標だけで判断しません。

- 条件が揃った実依頼を集められない場合：製品範囲と集客経路を見直します。
- 複数の供給企業から在庫確認を得られない場合：一般公開の品数拡大より供給開拓を優先します。
- 顧客が紹介は希望しても有料条件に同意しない場合：売買成立率と別に料金モデルを見直します。
- 実測した時間・費用を入れると期待貢献が負になる場合：件数拡大を止め、対象・料金・運用を再設計します。
- 法的な役割分担、保証・返金、個人情報の扱いが確定しない場合：デモと無契約の検証準備を続け、有料取引を開始しません。

## 6. 法的確認と参照資料

「部品を買い取らない」「未使用品である」「B2Bである」だけで許認可不要とは判断しません。愛知県警は、販売委託を受けて販売後に手数料を得る営業を古物商許可が必要な例として挙げています。警察庁の概要では、未使用でも使用のために取引された物が古物の定義に含まれます。

また、公開競りと非公開の見積依頼は同じ構造ではありません。神奈川県警の説明では、入札者が相互の提示条件を知れるか等を含めて「競りの方法」が説明されています。具体的な機能・契約・金銭の流れを提示して、個別に確認する必要があります。
