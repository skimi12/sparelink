## 実装の前提

Vinext + React + TypeScript + Cloudflare D1。Sitesが提供するChatGPTサインインを使用。一般閲覧は公開デモを想定し、実受付は `SPARELINK_ACCEPTING_SUBMISSIONS=false`。管理者メールの許可リストはサーバーの環境変数にのみ設定する。

受付停止中も管理者は架空のテスト記録を保存できる。`isTest` を公開カタログと他社へのマッチ候補から除外する。実レコードは審査後に公開対象となる。連絡先・企業名・自由記述・所有者IDを公開APIへ出さない。

料金は将来の検証案であり、現在は請求機能を起動しない。決済、買い取り、入札、発送、営業連絡は実行しない。実在する運営者情報や許認可、保証条件は未確定。作り話で補わない。

## 初回で判明した外部の障害

1. GitHub連携ではアカウントと既存リポジトリの読み書きは可能だが、新規リポジトリ作成機能がない。CLIは未ログイン、ブラウザの新規作成画面はログインを要求した。新規リポジトリ作成に必要な利用者操作が残る。無関係な既存リポジトリへ投稿して代替しない。
2. 毎時の定期タスク作成は `too_many_active_automations`（現在の上限20件）で拒否された。SpareLinkの新規定期タスクは作成されていない。既存タスクを停止・置換するにはユーザーの選択が必要。別の機能から同じ上限を回避しない。
